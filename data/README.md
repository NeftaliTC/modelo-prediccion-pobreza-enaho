# Datos

Esta carpeta organiza los datos de trabajo de la investigación. Los archivos de datos ENAHO (CSV, Excel y otros formatos), tanto originales como derivados, no deben subirse a GitHub.

- `raw/`: archivos originales, conservados sin modificaciones.
- `interim/`: datos intermedios generados durante la limpieza o integración.
- `processed/`: conjuntos preparados para análisis o modelado.
